# Homelab Index

Este repositorio centraliza la documentación, configuración y gestión del entorno de Homelab. Sirve como punto de entrada para comprender la arquitectura del sistema, los servicios desplegados y los procedimientos de mantenimiento y despliegue.

## Guías Principales

- [[Estructura]] — Organización de archivos y directorios del proyecto.
- [[Convenciones]] — Estándares de configuración para Docker y variables de entorno.
- [[Servicios]] — Catálogo de aplicaciones, asignación de puertos y límites de recursos.
- [[ServidorPi]] — Especificaciones técnicas del hardware y conectividad del host.
- [[Despliegue]] — Flujo de trabajo paso a paso para desplegar y actualizar servicios.

## Notas y Planificación

- [[Discord]] — Documentación relacionada con la integración o gestión de Discord.
- [[ListaDeIdeas]] — Backlog de servicios y mejoras pendientes para el entorno.
