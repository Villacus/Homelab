# Homelab Configuration

This repository contains Docker configurations and documentation for the homelab deployed on the Raspberry Pi (`pilla`).

## Documentation Style
Whenever documentation is requested or created, it MUST be maintained in the `docs/` directory following this Obsidian style guide:

1. **Naming**: Use capitalized/PascalCase filenames (e.g., `Estructura.md`, `ListaDeIdeas.md`).
2. **Formatting**: Do NOT include a top-level H1 header (`# Title`) inside the markdown file, as the filename acts as the title in Obsidian. Start directly with content.
3. **Navigation**: Use `[[wikilink]]` syntax for internal navigation.
4. **Index**: Ensure `docs/Index.md` is updated and linked whenever a new documentation file is created.
5. **Organization**: Keep all documentation centralized within the `docs/` folder.
